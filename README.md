## 📌 About the Project
College Event Management System is a MERN-based web application that helps colleges create, manage, and organize events easily. It allows users to manage event details such as event name, date, time, venue, organizers, and participants.

## 🛠️ Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

## ✨ Features
- Create and manage college events
- View event details
- Update event information
- Delete events
- Manage organizers and participants
- Store event data in MongoDB
- User-friendly interface

## 🔄 CRUD Operations
- Create – Add new events
- Read – View event details
- Update – Edit event information
- Delete – Remove events
